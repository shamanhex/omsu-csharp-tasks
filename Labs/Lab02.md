# Рекурсивный калькулятор

Необходимо доработать консольное приложение в проекте `src/Labs`. Приложение работает только в неинтерактивном режиме: интерактивное меню отсутствует, все данные передаются через аргументы командной строки.

## Аргументы командной строки

| Аргумент | Описание                                      |
| -------- | --------------------------------------------- |
| `--task` | номер выполняемого задания                    |
| `-d1st`  | начало первого отрезка дат, формат ДД.ММ.ГГГГ |
| `-d1end` | конец первого отрезка дат, формат ДД.ММ.ГГГГ  |
| `-d2st`  | начало второго отрезка дат, формат ДД.ММ.ГГГГ |
| `-d2end` | конец второго отрезка дат, формат ДД.ММ.ГГГГ  |

Аргументы могут указываться в любом порядке. В рамках данной лабораторной работы реализуется задание `--task 2` — рекурсивный расчёт по пересечению отрезков дат. Задание `--task 1` реализовано в лабораторной работе № 1 и должно продолжать работать.

## Базовые требования

1. Приложение должно находиться в проекте `src/Labs` и представлять собой единое консольное приложение (в дальнейшем оно дорабатывается в рамках последующих лабораторных работ).
2. При запуске без аргументов на экран выводится справка. Первая строка справки должна начинаться с `HELP:`, далее — текст в свободной форме, описывающий режимы работы и аргументы.
3. Аргумент `--task` задаёт номер выполняемого задания. Допустимые значения — `1` и `2`. Значение меньше 1 или больше 2 — ошибка.
4. Даты передаются аргументами `-d1st`, `-d1end`, `-d2st`, `-d2end` в формате `ДД.ММ.ГГГГ`. Другие форматы считаются некорректными. Например, некорректными будут: 1.09.2020, 10.9.2020 и 10.10.20.
5. Из двух отрезков дат вычисляется длина их пересечения N (в днях). ВАЖНО! При расчёте концы отрезка обязательно включаются в расчёт. Например, отрезки 12.12.2020 — 17.12.2020 и 10.12.2020 — 15.12.2020 пересекаются 12, 13, 14 и 15 числа, то есть N = 4. Если отрезки не пересекаются, N = 0.
6. Рекурсивная формула выдаётся индивидуально (см. раздел «Формулы»).
7. Расчёт рекурсивной формулы должен быть вынесен в отдельный рекурсивный метод.
8. Результат выводится двумя строками: сначала `DAYS: <N>` (длина пересечения), затем `RESULT: <R>` (значение формулы). Значение `R` форматируется до 3 знаков после запятой (пример: `120.000`).
9. Все входные аргументы должны контролироваться на корректность и непротиворечивость: корректность формата и существование даты, конец отрезка не раньше его начала и пр. При ошибке выводится строка, начинающаяся с `ERROR:`, с пояснением; программа завершается, не запрашивая значение повторно.
10. Необходимо ввести ограничение на значение N (ограничение устанавливается самостоятельно; расчёт должен проходить успешно и занимать не более 3 секунд). При превышении ограничения выводится `ERROR: ...` с пояснением.
11. Вывод `NaN`, аварийное завершение программы при корректных входных данных, а также бесконечная рекурсия — незачёт.
12. Должна осуществляться проверка на заведомо некорректные значения («проверка на дурака»): нечисловые строки, некорректные даты (например, 31 февраля) и пр. должны приводить к выводу сообщения об ошибке, начинающегося с `ERROR:`.
13. Код должен быть оформлен в соответствии с требованиями:
	- Отступы
	- 1 строка - 1 оператор
	- Расчёт формулы оформляется отдельным методом
	- Каждое задание (--task) - отдельный метод
	- Выбор задания (--task) реализовать через switch
	- Вывод на экран/typesafe чтение и др. самостоятельные операции - вынести в отдельные методы
	- Имена переменных - осмысленные (в идеале венгерская нотация: [https://ru.wikipedia.org/wiki/%D0%92%D0%B5%D0%BD%D0%B3%D0%B5%D1%80%D1%81%D0%BA%D0%B0%D1%8F_%D0%BD%D0%BE%D1%82%D0%B0%D1%86%D0%B8%D1%8F])

## Формулы по вариантам

```
1. Сумма всех чётных чисел от 0 до N
2. Функция Аккермана (m - длина отрезка пересечения дат, n = 5)
3. Наибольшая степень двойки, не превосходящая N
4. Наибольший простой делитель числа N
5. Количество простых чисел, не превосходящих N
6. Факториал
7. Сумма всех натуральных чисел до N
8. N-е число Фибоначчи
```

Уточнения к формулам:

1. Суммируются все чётные числа от 0 до N включительно (0, 2, 4, ...).
2. Функция Аккермана: A(0, n) = n + 1; A(m, 0) = A(m - 1, 1); A(m, n) = A(m - 1, A(m, n - 1)). Здесь m = N, n = 5. Обратите внимание: при N ≥ 4 результат не может быть вычислен за отведённое время.
3. Результат — наибольшее число вида 2^k, не превосходящее N. При N = 0 такого числа не существует — вывести `ERROR:`.
4. Результат — наибольший простой делитель числа N. При N = 1 результатом является 1. При N = 0 результата не существует — вывести `ERROR:`. Если N — простое число, результатом является само N.
5. Результат — количество простых чисел, не превосходящих N.
6. Факториал N!, при этом 0! = 1.
7. Сумма натуральных чисел от 1 до N; при N = 0 сумма равна 0.
8. Последовательность Фибоначчи: F(0) = 0, F(1) = 1, F(n) = F(n - 1) + F(n - 2). Результат — F(N).

## Приёмка

### Критерии автоматизированной приёмки

Автоматизированный контроль анализирует только первые строки вывода:

- Вывод справки начинается со строки `HELP:`.
- При успешном расчёте первая значимая строка начинается с `DAYS:`, вторая — с `RESULT:`.
- Вывод ошибки начинается со строки `ERROR:`.
- Пустые строки в начале вывода игнорируются.
- Всё, что выводится после проверяемых строк, при анализе успешности игнорируется.

### Запуск без аргументов

```
.\Labs.exe
HELP:
    --task - task number
	...
    -d1st - start of the first date segment (DD.MM.YYYY)
    -d1end - end of the first date segment (DD.MM.YYYY)
    -d2st - start of the second date segment (DD.MM.YYYY)
    -d2end - end of the second date segment (DD.MM.YYYY)
```

### Ввод числа вне диапазона

Программа должна выходить с ошибкой, если `--task` меньше 1 или больше 2:

```
.\Labs.exe --task 3 -d1st 12.12.2020 -d1end 17.12.2020 -d2st 10.12.2020 -d2end 15.12.2020
ERROR: Unknown task. Task number must not exceed 2.
```
```
.\Labs.exe --task 0 -d1st 12.12.2020 -d1end 17.12.2020 -d2st 10.12.2020 -d2end 15.12.2020
ERROR: Unknown task. Task number cannot be less than 1.
```

### Ввод некорректного числа

Программа должна выходить с ошибкой, если `--task` не является целым числом:

```
.\Labs.exe --task one -d1st 12.12.2020 -d1end 17.12.2020 -d2st 10.12.2020 -d2end 15.12.2020
ERROR: Task number must be an integer.
```
```
.\Labs.exe --task 2.0 -d1st 12.12.2020 -d1end 17.12.2020 -d2st 10.12.2020 -d2end 15.12.2020
ERROR: Task number must be an integer.
```

### Некорректное значение параметра

```
.\Labs.exe --task 2 -d1st 32.12.2020 -d1end 17.12.2020 -d2st 10.12.2020 -d2end 15.12.2020
ERROR: Value D1ST must be a valid date in format DD.MM.YYYY.
```

### Обратный порядок дат в отрезке

Программа должна выходить с ошибкой, если конец отрезка раньше его начала:

```
.\Labs.exe --task 2 -d1st 17.12.2020 -d1end 12.12.2020 -d2st 10.12.2020 -d2end 15.12.2020
ERROR: End of the first segment must not be earlier than its start.
```

### Успешный запуск

```
.\Labs.exe --task 2 -d1st 12.12.2020 -d1end 17.12.2020 -d2st 10.12.2020 -d2end 15.12.2020
DAYS: 4
RESULT: 6.000
```

(результат приведён для варианта 1: сумма чётных чисел от 0 до 4 равна 0 + 2 + 4 = 6)
