# Задание 3. Работа со строками

Необходимо разработать консольное приложение, состоящее из меню следующего вида:

```
[0] Exit
[1] Hello World!
[2] Calc: <formula>
[3] Recursion date 
[4] Strings
```

## Базовые требования

1. Реализовать ввод 2 строк
2. Вывести на экран результат 4 проверок:
	- Совпадают ли они посимвольно
	- Если привести к одному регистру, удалить пробелы в начале и в конце, а так же дублирование пробелов. Тройные пробелы и более подряд идущих пробельных символов должны превращаться в 1 пробел.
	- Является ли 1-я строка перевёртышем ко 2-й (символы в обратной последовательности)
	- Являются ли строки: email, тел. номером, IP-адресом.

## Используйте RegEx для проверки шаблона

Для проверки шаблона email, IP или тел. номера следует использовать RegEx. 

```
RegEx для Email:    [^@ \t\r\n]+@[^@ \t\r\n]+\.[^@ \t\r\n]+
RegEx для IPv4:     (\b25[0-5]|\b2[0-4][0-9]|\b[01]?[0-9][0-9]?)(\.(25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)){3}
RegEx для Телефона: ^[\+]?[(]?[0-9]{3}[)]?[-\s\.]?[0-9]{3}[-\s\.]?[0-9]{4,6}$
```

Больше примеров regex можно найти на сайте: <https://ihateregex.io/>

## Дополнительные требования
1. Отрефакторить код приложения следующим образом:
	- Выделить класс Task как задание в меню. Реализовать классы-наследники от Task для всех пунктов меню.
2. Разделить реализацию ввода данных и обработки. Функции проверки значений/расчёта/... не должны содержать в себе операции чтения, а должны принимать необходимые значения как параметры.

## Приёмка

1. Проверить, что предыдущий функционал работает.
2. Код приложения должен представлять собой набор классов, каждый из которых реализует определённый функционал меню.

Дополнительно:

3. Проверить, что методы проверки строк/расчёта формул и пр. обработки не содержат кода чтения с экрана.
